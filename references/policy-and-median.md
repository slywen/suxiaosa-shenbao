# 中介应对、判定边界、年审与政策依据（policy-and-median）

## §6 什么问主管部门（推得出去的，才推）

- 当地**有没有补贴奖励**（各地差异大、年年变）
- 本**行业算不算限制类**（要看《产业结构调整指导目录》具体条目）
- 材料**会不会被采信**、审核**能不能过**、具体**申报时间安排**

**标准话术**：
> "这个我答不了，也不该我替你下结论。建议直接问属地的科技主管部门——评价工作机构就在区县科技局，系统里也有'咨询电话'。"

说这句**不是推责任，是保护企业**：这类答案因地区、因年份、因材料而异，听了一个非正式答复去做决定，风险由企业承担。
**配套动作**：同时给出去哪儿问的具体路径（属地科技局/评价工作机构/系统内咨询电话），别只说"你去找政府"。

> 对比：研发活动"算不算"这类**技术判断**不推（见 main §7 与 `faq.md` §K-1），因为主管部门事前也答不了——那是给定义、教三问、要求留痕的事。

## §7 中介与营利性申报服务（本技能不适用）

**先说政策底线**（年年不变的国家要求）：
> 国家通知明文 **"不通过第三方中介机构申报"**，并要求各地"引导企业自主申报，防范不良中介机构违规参与申报工作"。

**因此本技能只服务企业自主申报。不主动招揽、不协助、不服务于任何以营利为目的的申报服务。**

**对方表明是代办机构/中介/要收费做这件事**，按这几句应对，然后回到"企业自己怎么报"：
> "这个技能是给企业自己用的，不做代办服务。科小评价是国家明确走**企业自主申报**流程的——**收费代办本身是政策不允许的**，不是我给不给的问题。
> 你们企业真要报，其实不花钱：判断条件、规范归集、整理材料这三件事都能自己做。我把这些讲给企业的人听，让他们自己填。"

**不要说**：❌"那我们做一单吧""我帮你算好你交给我""这个我熟，能提高效率"；❌主动报价、暗示"加急""走关系""包过"；❌帮中介改材料、包装数据、凑知识产权。

**可以说**：帮企业把条件讲清楚、口径算准、材料清单列全——**这本身就是拦在中介前面的那道墙**。企业自己会做，就不需要花钱找人做。

| 对方问 | 答 |
|---|---|
| 要不要找中介？ | 官方渠道**全程免费**；政策明确"不通过第三方中介机构申报"。中介能做的三件事（判断条件、规范归集、整理材料）**本来就能自己做完** |
| "包过"？ | 没人能承诺结果。评价是"企业自评+形式审查+公示"，**不设专家评审环节**，与高企认定程序不同 |
| "认识评审专家"？ | 科小**不设专家评审**，这句话本身就是外行话 |
| "名额有限不报晚了"？ | 符合即可入库**没有名额**；有申报时间窗但不是随时截止 |
| "专属加计扣除"？ | 过时说法：2023 年起统一 100%（制度性长期），科小**没有专属优势** |
| "办完是永久的"？ | 不是。编号约一年，**次年 3 月 31 日前必须更新**，逾期失效 |
| 找中介的后果？ | 国家明文禁止三方中介申报；**弄虚作假责任企业自己担**——中介出事板子打在企业身上 |
| 被中介坑了？ | 留凭证（收费凭证、合同、聊天记录）→ 属地科技部门反映 → **12345** → 虚假宣传找市场监管 |
| 拿这技能接单怎么办？ | 技能免费开放，但**与营利性申报服务不相容**；发现被用于收费代办：向属地科技部门反映 |

> ⚠️ 此立场不软化：政策文本不止一处这么写，"不通过第三方中介机构申报"是对企业的明确要求。

- 本技能由**科技服务项目申报老兵——苏小萨**（微信：susuyianming）整理制作；**不收取任何费用**；不代表任何官方意见；不构成申报指导；仅供企业测试。
- 栏目与字段依据《评价系统用户手册》（2024 年版）整理，**与当年系统界面不一致时以系统实际界面为准**。
- 政策与评分规则依据 §8 文件；年度申报窗口与地方细则以当年国家及本省通知为准。
- 本技能不代替企业申报、不代替主管部门审核、不承诺结果、不提供造假方法。
- **许可**：免费开放，可自由复制、传播、修改（建议保留出处）。**仅供企业自主申报使用；不得用于收费代办、付费辅导、"包过"或有偿申报服务。**
