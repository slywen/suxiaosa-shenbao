# 字段与栏目（fields）

本文件三段：§A 全量字段速查表（只给熟手，或生手明确要"全部"）；§B 生手栏序地图；§G 熟手勾稽关系。
**§A 不是默认输出**：生手问一栏答一栏，不许把这份倒给他；熟手一次要，才连同 §G 一起给。

## §G 熟手勾稽关系（必查，错一个就退回）

- 各学历人数相加**必须 = 职工总数**（博士+硕士+本科+大专及以下），凑不平提交不了
- **研发费用总额 = 各研发项目"当年实际发生费用"之和**（系统自动算，不要手填）
- 《企业数据》（万元）必须与 **资产负债表、损益表、纳税申报表三表对得上**
- 《企业职工人数统计表》上的科技人员数 **= 系统人力资源表里填的科技人员数**（核查第一个对的地方）
- 季平均只用于职工总数、科技人员数两项；资产总额是期末数（口径见主 SKILL.md §0.5）
- 单位：企业数据=万元（两位小数），加计扣除金额=元

**熟手三件套**：①上面勾稽 ②生死线五条（主 SKILL.md §4.4）③提分杠杆（`scoring.md` §5）。
他问"我这样填对不对"→ 逐项过、只报错处，全对就说"这组没问题"。

## §B 生手栏序地图（每栏只讲：填什么 / 从哪来 / 填错会怎样）

| 系统步骤 | 栏目 | 填什么 | 从哪来 | 填错会怎样 |
|---|---|---|---|---|
| ① 企业信息 | 核对信息 | 名称、信用代码、注册地、法代、成立日期、所属行业 | 营业执照+注册信息 | 系统带出，一般不用改；须与营业执照一致 |
| ② 填报说明 | 勾选 | 读完勾"我已仔细阅读并知悉填报说明" | 系统内《填报说明》 | **不勾点不了下一步** |
| ③ | 【一】企业基本信息 | 企业规模（大中小微，按《中小企业划型标准规定》）、企业类型（国有/合资/民营/外资）、联系人姓名/电话/证件（填实际办业务的人） | 自报+划型标准 | 🖐必填不作为评价依据，**空着提交不了** |
| ③ | 【二】基本准入条件判定 | 产品及服务范围、企业信用，**两项都要"符合"** | 禁限淘汰类；经营异常名录 | 🔴 生死线③：任一项"不符合"直接不通过 |
| ③ | 【三】高新技术企业 | **不用填**，系统自动获取 | — | 显示"否"但实为高企 → 等认定工作结束后再填 |
| ③ | 【四】其他重要条件判定 | 辅助账是否设置(🔴)、是否享受加计扣除、上一年10月是否提前享受、加计扣除金额（**元**） | 见主 SKILL.md §3 坑1 | 🔴 **生死线①：辅助账填"否"直接判不符合** |
| ③ | 【五】企业研发项目 | 逐条增行：所属年份、名称、编号、研发形式（自主/合作/集中/委托境内/委托境外）、实施状态（已完成/未完成）、当年实际发生费用（万元） | 企业真实立项记录 | 🔴 **生死线④：漏填→研发费用总额 0→收入占比 0 分，50 分全丢**；项目所属年份必须=立项年份且与发生额年份一致 |
| ③ | 【六】企业数据 | 资产、净资产、销售收入、主营收入、利润、纳税、成本费用、研发费用（自动）、高新产品收入、负债、年末所有者权益、技术合同成交额、减免额、风投、股权融资、净利润 | 会计报表+纳税申报表 | 🔴 **单位错一档（万/元）全盘对不上**；填期末数、万元、两位小数；"XXXX年企业数据"年号取上一年度；系统会同时显示上一年/本年两组，是历史对照不是填两遍 |
| ③ | 【七】人力资源情况表 | 职工（在职/兼职/临时）、科技人员（在职/兼职/临时）、本年新增、吸纳毕业生、学历四项、职称四项 | 花名册+社保 | 🔴 **生死线②：<10% 直接 0 分**；学历四项相加必须=职工总数；兼职/临时人员须全年累计满 6 个月才可计入科技人员，在职人员无此要求 |
| ③ | 【八】上年度主要产品情况表 | 1–3 条：产品名、技术领域、行业领域（方框点选）、从事年限、主导产品类型、行业领军企业（填**本企业**认定情况，3个以内） | 销售合同/产品说明 | 🔴 **生死线⑤：行业领域须与研发项目性质一致**；领军企业填别家公司=明显错填 |
| ③ | 【九】企业知识产权情况表 | 点"获取知识产权信息"批量勾选**状态为有效**的（六类）；手动新增的上传证明（1M 内）；Ⅰ/Ⅱ类件数、PCT 与发明专利申请量 | 六类知识产权 | 0 项**不直接否**，但**触发实地核查**；不相关、过期、有权属争议的不计入 |
| ③ | 【十】直通车相关 | 标准制定、研发机构（名称/级别/证明）；国家级科技奖励系统自动获取 | 有就填没有空着 | 空着不影响 |
| ③ | 【十一】佐证材料 | 4 份盖章扫描 PDF → 传「佐证记录」 | `materials.md` | 缺材料退回 |
| ③ | 【十一之二】封面文件 | 信息表封面：法代签字/签章+公章扫描件 → 传「封面文件」 | **自评显示"符合"之后**才可下载 | 缺不能提交 |
| ③ | 【十一之三】已入账申报表 | **不用管** | 享受过加计扣除的系统/税务侧带数据过来 | 没享受过是空的，**不是漏填** |
| ③ | 【十二】科技创新建设 | 近两年省级以上平台数/科技奖励数/科技计划项目数 | 有就填没有填 0 | 🖐必填但不作为评价依据 |
| ③ | 【十三】其他信息 | 荣誉情况、是否战略性新兴产业（选到具体分类）、其他说明 | — | 非评价依据 |
| ③ | 【十四】融资需求 | 🖐**必填但有"是否选填"开关，选"否"后全留空是合规的** | — | **必填≠必须填内容**；别逼企业编融资需求；空着但没选"否"提交不了 |
| ④ 自评结果 | 核对 | 总分与"符合/不符合" | 系统自动算 | 不符合 → 系统给原因，回上一步改 |

页面顶部三个标签页：**封面文件 / 佐证记录 / 已入账申报表**，别传错位置。

**生手对话形态**（对错示范）：

> 企业："③企业数据，资产总额怎么填？"
> ✅"填上一年度会计报表的**期末数**，不是平均数。**万元、两位小数**，如 860.42。这栏错不直接影响分，但会跟净资产、负债总额对不上——填完往下核那两栏。"
> ❌ 甩 14 栏全量模板 + 5000 字。

> 企业："研发项目一直填 0 行行不行？"
> ✅"**不行，这是最容易致命的坑**：研发费用总额是系统按项目表自动汇总的，表空=0 分项=50 分全丢。把去年真实做过的项目列出来：年份/名称/研发形式/状态/当年实际发生额。没立项的，先补一个立项决议再录。"
