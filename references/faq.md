# 高频问答库（faq）

> 用法：企业问到哪条照哪条答，答完再按主 SKILL.md 路由深入。括号里是依据，可说文号也可只说结论，看对方接受度。

## §A 能不能报

| 问 | 答 |
|---|---|
| 去年才成立，能报吗？ | 需至少**一个完整年度**数据，评价用上一年度人员和财务数据；部分地区明确要求成立满 365 天（如天津，往要求、逐年核）。→ 新设企业先问属地主管部门是否受理，不确定等下一年度再报，不要硬填 |
| 规模大能报吗？ | 职工 ≤500 人、年销售收入 ≤2 亿、资产总额 ≤2 亿，任一超了不符合 |
| 做贸易的/餐饮的能报吗？ | 行业不能属于禁止、限制和淘汰类；且国家通知明确**"严禁将单纯从事商贸流通、简单组装加工、无自主研发活动的企业包装入库"**——关键是有没有真实研发活动 |
| 负面清单行业能报吗？ | 🔴 不建议：烟草制造、住宿餐饮、批发零售、房地产、租赁商务服务、娱乐业。①主要红利（加计扣除）用不上 ②难有真实研发，会被重点核查。确有真实研发可报，做好被查准备 |
| 分公司/办事处能报吗？ | 必须是境内注册的**居民企业（独立法人）**；分公司一般不符合 |
| 有高企证书还要报科小吗？ | 高企资格系统自动获取，是直通车条件，可直接确认；且科小是申报**专精特新**的台阶（梯度培育办法） |
| 被列入经营异常名录能报吗？ | 🔴 **不能**，硬门槛。先在国家企业信用信息公示系统把异常修复掉再来 |
| 没有知识产权能报吗？ | 可以报，但①科技成果 0 分（满分30）②知产为 0 **触发实地核查** ③没有辅助账会直接判"不符合"（见 §K-2） |
| 研发费用很少有问题吗？ | 年度研发费用**<10 万元触发实地核查**；研发投入占 50 分，太低拉垮总分 |
| 科小有什么用？ | ①政策优先支持 ②申报专精特新的台阶 ③融资支持（科技信贷、贴息）④采购/招投标加分 ⑤各地配套差异大，问属地 |

## §B 数据怎么算（最容易错的一节）

| 问 | 答 |
|---|---|
| 单位是什么？ | 🔴 两套单位：《企业数据》全栏**万元**（两位小数）；《其他重要条件判定》加计扣除金额是**元**。⚠️ 以系统页面实际提示为准，填前再确认一次——全技能最易出数量级错误处 |
| 资产总额填期末还是平均？ | 🔴 **上一会计年度会计报表期末数**（《评价办法》指标说明第六项+《填报说明》第3条）。资产总额不适用季平均 |
| 哪些要季平均？ | **只有职工总数和科技人员数**：季平均=（季初+季末）÷2，全年季平均=各季平均之和÷4。月平均是**高企**认定口径，别混；"183天"也是高企口径，不是科小口径 |
| 职工总数怎么算？ | 在职+兼职+临时聘用，按全年季平均。备注：各学历人数相加必须=职工总数 |
| 科技人员怎么算？ | 直接从事研发和相关技术创新活动、及其管理与直接服务人员，**在职、兼职、临时三类都算**；兼职/临时须全年在本企业累计满 6 个月，在职人员无此要求（别只讲后半句让人误以为正式员工的研发工时不用管） |
| 销售收入口径？ | 主营业务收入 + 其他业务收入 |
| 成本费用总额怎么算？ | 企业所得税年度申报表口径：营业成本+营业税金及附加+销售费用+管理费用+财务费用 |
| 利润总额？ | 营业利润+营业外收入−营业外支出 |
| 净资产？ | （期初+期末）÷2 |
| 研发费用总额要自己填吗？ | 🔴 **不用填**，系统按研发项目明细自动汇总；手填反而错 |
| 研发费用归集口径？ | 财税〔2015〕119号（与加计扣除同口径）；委托境内按实际发生额 80% 计入；委托境外 80% 且不超过境内符合费用 2/3 |
| 研发项目格子怎么填？ | 所属年份/名称/编号/研发形式/实施状态/当年实际发生费用（万元）；**所属年份=立项年份且=发生额年份** |
| 哪些系统自动算？ | 研发费用总额、职工总数、科技人员总数、知产数量、高企资格、近五年国家级科技奖励 |

## §C 材料细分问答

| 问 | 答 |
|---|---|
| 要交哪些材料？ | 4 份佐证（加盖公章、PDF、≤1M）：①职工人数统计表（注明科技人员数）②资产负债表 ③损益表 ④A类A107012 **或** 研发项目辅助账；封面单独下载签字盖章传「封面文件」；"其他证明材料"非必须看当地 |
| 封面什么时候下载？ | 自评显示"符合"之后，没到"符合"下载不了 |
| 职工人数统计表有模板吗？ | 系统可下载《企业上一年度职工人数统计表模板》，填→印→章→扫→传；表上科技人员数必须与系统【七】一致 |
| 没有 A107012 怎么办？ | 佐证二选一：享受过加计扣除的用 A107012；没享受的**自己整理辅助账**（系统可下载《研发支出辅助账汇总表》模板；已有自行整理的以自行整理的为准） |
| 辅助账和加计扣除什么关系？ | 判断顺序见 main §3 坑1 与 `aux-account.md` |
| 软著算Ⅰ类还是Ⅱ类？ | **Ⅱ类**。Ⅰ类：发明、植物新品种、国家级农作物品种、国家新药、一级中药保护品种、集成电路布图 |
| 知产要传证明吗？ | 系统自动获取的不用；手动"新增"的才传（≤1M） |
| 知产怎么录最快？ | 点"获取知识产权信息"按类型查询，勾**状态"有效"**的批量提交 |
| 要审计报告吗？ | 手册要求的 4 份里**没有**审计报告；按当地要求 |
| 知产与主要产品无关行吗？ | 不行，要求**相关**、有效期内、无争议——不相关不计入 |

## §D 系统操作

| 问 | 答 |
|---|---|
| 从哪进？ | `https://zjtx.miit.gov.cn/` → 梯度培育 → 科技型中小企业 → 立即前往 → 新增评价信息 |
| 几步？ | ①企业信息 → ②填报说明 → ③企业主要数据 → ④自评结果 |
| "本年度已存在评价信息表"？ | 今年已新增过，不能重复添加；去"评价信息"列表点【修改】继续 |
| 怕丢？ | 页面下方【保存】随时点，避免登录失效丢数据 |
| 🖐是什么？ | 必填但不作为评价依据（联系人、科技创新建设、融资需求等）；**必填≠必须填内容**，融资需求选"否"留空合规 |
| 高企显示"否"我们是高企？ | 系统自动获取；高企备案未结束所致，等认定工作结束后（往年提到 9 月）再填 |
| 要选评价机构？ | **必选**，否则不能提交；页面有咨询电话 |
| 提交后能改吗？ | 状态"评价机构形式审查"时可**撤回**→修改→重传→重新提交 |
| 怎么看进度？ | 操作栏【审核记录】；公示期 **10 个工作日** |
| 浏览器？ | Chrome；360 极速（9.1+）或兼容（IE9+） |
| 表格不满？ | 各栏目不得空缺，无内容填"0"；小数保留两位 |
| 两组研发费用？ | 系统同时显示上一年/本年，是历史对照，不是让你填两遍 |
| 上年研发费用 0？ | 评价看上一年度，无直接影响，但会被当"指标异常"盯上，抽查重点核"突增突减"；确实没做研发说明白即可 |
| 领军企业填别家行吗？ | **不能**，填的是**本企业**认定情况，核查直接问 |
| 行业领域和研发项目对不上？ | 多表打架最常被查；要么改产品行业到与研发一致，要么备好书面说明 |
| 项目名称填"无"行吗？ | 不建议；没做研发整行删掉比留"无"干净 |

## §E 入库之后

| 问 | 答 |
|---|---|
| 是永久的吗？ | 否。编号有效期约一年（公告之日起至**次年 3 月 31 日**前） |
| 什么时候更新？ | 次年 1月1日—3月31日通过系统更新《信息表》，**3月31日是硬截止**；忘了→编号失效（写进年初日历） |
| 规模超了？ | 任一超标（>500人/>2亿/>2亿）不再符合无法更新；提前规划高企、专精特新 |
| 会被撤销吗？ | ①重大变化不再符合 ②严重弄虚作假 ③科研严重失信 ④重大安全/质量事故、严重环境违法 ⑤列入异常名录 ⑥**未按期更新** |
| 更名了？ | 3 个月内通过平台填报，不得不瞒 |

## §F 核查与抽查

| 问 | 答 |
|---|---|
| 谁会被上门核查？ | 五类（逐年核）：①职工 ≤5人 ②知产=0 ③研发费 <10万 ④近三年失信/被撤销编号 ⑤**首次参评**。核查在**公示前** |
| 入库后还查吗？ | 每批次公告入库后 ≥5% 随机抽查（上限原文），不符合的撤号；原则上不含有效期内创新型/专精特新、以及高企直通确认的科小；同一家（抽查符合）三年内仅查一次 |
| 查什么？ | 实际经营状况、资料真实性、数据一致性；抽查重点：指标异常、数据矛盾、突增突减 |
| 准备什么？ | 立项决议、项目计划书、**工时记录**（兼职研发必备）、材料领用单（项目编号/用途/领用部门/审批）、结题/执行报告、测试报告或专利受理通知——这些是研发活动**本来就该有**的记录，不是额外材料 |
| 现场问什么？ | 不问"是不是"只问"怎么做的"："上一个项目谁负责、何时立项、解决什么问题、到哪一步"——要**研发人员本人**回答；"这个软著对应的软件在哪台机器上？能打开吗？" |
| 没留记录？ | 现在补来得及——**补记录和编记录的区别在于事情是否真实发生过**。真实做过但没留痕：讲清过程、找原始凭证，比漂亮假账有说服力 |

## §H 高频误区纠正

| 误区 | 正解 |
|---|---|
| 科小永久有效 | 约 1 年，3月31日前必须更新 |
| 科小有专属加计扣除 | 过时：2023 年起统一 100%（制度性长期），科小无专属优势 |
| 科小=高企 | 科小是**评价入库**；高企是**认定**（15% 税率）；可叠加，高企是科小直通车 |
| 有高企就不用报科小 | 高企直通确认科小；科小是专精特新台阶 |
| 找中介更容易过 | 通知明确"不通过第三方中介机构申报"；造假责任企业自己担 |
| 评价要收费 | 全程免费，官方宣讲培训也免费 |
| 规模大也能报 | 任一超标即不符合 |
| "名额有限趁早" | 符合即可入库**无名额限制**；有申报时间窗但不是随时截止 |
| "科小专属加计比例更高" | 同上 2023 统一 100% |
| "包过/认识评审专家" | 科小**不设专家评审环节**，是"企业自评+形式审查+公示"；承诺结果本身是外行话 |

## §K-1 研发活动怎么判（企业自判，留痕）

**这类问题主管部门事前也答不了**——审核是拿企业留存的立项/过程/结题记录**事后验证**的，不是看行业。所以：给定义→教三问→要求留痕，别推给主管部门。

**定义**（财税〔2015〕119号）：为获得科学与技术新知识、创造性运用科学技术新知识、或实质性改进技术产品（服务）工艺而**持续进行的、具有明确目标的系统性活动**。

**七类排除（不属于研发活动）**：①产品（服务）的常规性升级 ②对科研成果的直接应用 ③商品化后为顾客提供的技术支持 ④对现存产品/服务/技术/材料/工艺的重复或简单改变 ⑤市场调查、效率调查或管理研究 ⑥工业（服务）流程环节或常规的质量控制、测试分析、维修维护 ⑦社会科学、艺术或人文学研究。

**三问自判法**：①目标是不是"获得新科技知识"或"实质性改进"；②是不是重复/简单改动、直接套现成技术；③是不是常规质检、维保、市场调查。

**说完必须补三句**：①"这个判断你们自己做，依据就是上面定义和排除；我不替你判，主管部门事前也判不了" ②"判断完要留痕：立项决议、计划书、研发人员名单、工时记录、结题报告——审核看这些验证" ③"拿不准的处理：部分业务有研发性质的（如技改里混着研发），**把研发部分单独立项**，技改留在成本费用，两边各归各位"。

## §K-2 三个最容易栽的坑（主动讲，不属于生死线）

**坑1 · 辅助账判断顺序**（先问"享受过加计扣除吗"再谈辅助账）：
```
享受过加计扣除吗？
├─ 享受过 → 已有 A107012 → 佐证用它；辅助账通常本来就有
└─ 没享受过 → 没有 A107012 → 必须自己整理研发支出辅助账
              （佐证二选一 + 回答"是否设置辅助账"）
🔴 没加计扣除 + 没辅助账 = 两边都没有 = 先做辅助账，再申报
```
"是否设置辅助账"填"否"，自评**直接显示不符合**，连分数都不看——这恰是没做过加计扣除的企业最缺的。

**坑2 · 科技人员占比 <10%**：该指标 0 分，**一票否决**，总分再高也不能入库。

**坑3 · 弄虚作假**：取消本年度资格 + **三年内不得参与评价**；责任由**企业自己**承担，中介不担。⚠️ 此条属**事后惩罚**而非"填错就否"栏位，与生死线（五条，见 main §4.4）不是一个口径。
