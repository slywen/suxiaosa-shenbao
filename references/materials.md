# 材料：打印、盖章、扫描、上传（materials）

> 系统里的佐证材料，全部是企业**自有纸质件**扫描成的 PDF。这个技能不能替企业出任何材料。
> 企业问"要交什么"，答案永远是三件事：**要哪几份 → 怎么盖章 → 怎么扫描上传**——只报名字不说后两件，不合格。

## 1. 要打印、盖章、扫描、上传的材料清单

| 材料 | 怎么取得 | 盖章要求 | 扫描上传 |
|---|---|---|---|
| 《科技型中小企业信息表封面》 | 自评显示"符合"后，系统内**下载** | **法定代表人签字或签章 + 企业公章**（两样都要，缺一不可） | 扫描成图片或 PDF，**≤1M** → 传「封面文件」 |
| 《企业职工人数统计表（注明科技人员数）》 | 系统下载《企业上一年度职工人数统计表模板》，填好打印 | 企业公章 | PDF **≤1M** → 「佐证记录」 |
| 资产负债表 | 企业自己上一年度会计报表 | 企业公章 | PDF **≤1M** |
| 损益表（利润表） | 企业自己上一年度会计报表 | 企业公章 | PDF **≤1M** |
| A类A107012 **或** 研发项目辅助账（二选一，见 §3） | 享受过加计扣除的用 A107012；没享受的自己整理辅助账 | 企业公章 | PDF **≤1M** |

> 🔴 **"盖章"和"扫描"这两步最容易漏**。上传失败常不是数据问题，是 PDF 超 1M、或章盖不清楚被退回。
> 提醒口径：**300dpi 以上、模式选"文档"不要选"照片"**，一份材料通常 200–800KB，压到 1M 内完全够。

## 2. 系统里是哪几个上传口

页面顶部**三个标签页**：

| 标签页 | 传什么 | 谁准备 |
|---|---|---|
| **封面文件** | 信息表封面扫描件 | 系统内下载 → 签字盖章 → 扫描上传 |
| **佐证记录** | 上表 4 份佐证 | 企业自己盖章扫描 |
| **已入账申报表** | 享受过加计扣除的企业由系统/税务侧带数据 | **不用自己传**；没有就是空的，别慌 |

## 3. A107012 / 辅助账 二选一

- **享受过加计扣除** → 有 A107012，直接用；
- **没享受过** → 没有 A107012 → **必须自己整理研发支出辅助账**（系统可下载《研发支出辅助账汇总表》模板；已有自行整理的汇总表，以自行整理的为准）。
- 这份东西同时也是生死线①"是否设置研发支出辅助账"的底气——两个都没有时**必须先做辅助账再申报**（main §3 坑1）。
- 离线工具：`assets/研发费用辅助账自查工具.html`，下载双击、本地打开、按 2021 版官方格式（税总公告2021年28号）导出辅助账+汇总表。
