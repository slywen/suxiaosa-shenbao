> 能算分、能判定、能预警，不只是复述填报说明书。

## 这是什么

一个用于**科技型中小企业（科小）自主评价与申报**的 Agent Skill（Claude Code / OpenCode / Codex 等通用 SKILL.md 格式）。

官方《填报说明书》是静态的；这个技能能基于企业实际数据**完成判定、算分、勾稽核对和风险预警**，并告诉你差多少、怎么补最快。

## 适合谁

| 你的情况 | 你得到什么 |
|---|---|
| 企业填过、有经验 | 直接核数据：勾稽关系、生死线、提分杠杆。不讲流程、不甩全量模板 |
| 第一次填报 | 按系统栏序一栏一栏带，一次讲 3–5 栏 |
| 要准备材料 | 4 份佐证+封面：打印、盖章、扫描（≤1M）、上传标签页全流程 |
| 已填完想核对 | 逐项过，只报错处 |

| **时效数据硬纪律** | 抽查比例、成立年限要求、申报窗口等逐年会变的数字**必须带"以当年通知为准"**限定并给出"依据/截至/适用地区/时效"四元组 |
| **评估用例集** | `evals/cases.md` 10 组对话用例 + 通用话术 checklist，改版可回归测试 |

## 能回答什么

- **能不能报**：规模硬门槛、行业负面清单、信用合规、高企直通车
- **多少分**：科技人员占比 20 分 + 研发投入双口径取高 50 分 + 知识产权 30 分，**提分杠杆（下一档缺额）**
- **怎么填系统**：14 个栏目口径、单位（万元/元区分）、小数位、填错会怎样
- **数据怎么算**：季平均只用于职工/科技人员、资产总额取期末、自动项别手填
- **材料怎么办**：哪几份、怎么盖章、300dpi/文档模式、单份 ≤1M、传哪个标签页
- **辅助账怎么做**：A107012 与辅助账二选一判断顺序、八大类费用、三个限额、工时分配
- **会不会被查**：实地核查五类触发、抽查比例、原始凭证清单
- **入库之后**：有效期、3月31日更新硬截止、撤销情形、更名

## 两个离线工具（不联网、不上传）

下载对应文件，**双击在本机浏览器打开**（数据只存本机）：

1. `assets/科小算分工具.html` — 输入人数/费用/知产 → 立刻给出各指标分档、总分、及格判定、"补到下一档最少要投多少"
2. `assets/研发费用辅助账自查工具.html` — 研发费用归集与汇总表导出（2021 版官方格式）

> ⚠️ 在对话环境里直接"预览"这两个工具 = 沙箱、存储不可靠，**别填真实数据**；下载双击本地打开才是真正的离线。

## 隐私

企业财务/人员数据**只在当轮对话使用**，不写入任何文件、不留存、不外传。推荐给有隐私顾虑的用户使用两个离线工具完成明细录入。

## 使用限制

本技能**仅供企业自主申报使用**，免费开放。**不得用于收费代办、"包过"或有偿申报服务**——国家通知明文"不通过第三方中介机构申报"。技能不代替企业申报、不代替主管部门审核、不承诺结果、不提供造假方法。
